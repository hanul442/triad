# TRIAD 시가전

도시 한복판의 거점을 두고 분대 단위로 싸우는 3D 실시간 전술 게임입니다. 건물에 들어가 엄폐하고, 시야를 가리는 빌딩을 이용하고, 필요하면 건물째 무너뜨리세요. 2~4개 세력 중 하나를 사람이 지휘하고 나머지는 AI가 맡습니다.

**플레이:** https://hanul442.github.io/triad/ (main 브랜치 배포본)

**3D 시가전 개발 미리보기:** https://claude.ai/artifact/7zEiSXZZEW8Gu3uEPEhPPZ (feat/3d-urban 최신 빌드)

## 처음이라면

시작 화면의 **기초 훈련**부터 해보세요. 이동·엄폐·시야·사격·점령·증원을 6단계로 안내합니다.

| 시나리오 | 목표 |
| --- | --- |
| 기초 훈련 | 소형 도시에서 기본 조작 익히기 |
| 도심 돌파 | 적이 모든 거점을 쥔 도시에서 8분 안에 거점 5곳을 동시에 확보 |
| 최후 방어 | 도심 거점을 지키며 7분을 버티고 거점 3곳 이상 유지 |

## 캠페인: 하령 작전

가상의 내전 속 하령시에서 연방군을 지휘하는 임무 세 개입니다. 앞 임무를 마쳐야 다음 임무가 열리고, 임무마다 별을 세 개까지 받습니다(기록은 이 기기에 저장).

| 임무 | 목표 |
| --- | --- |
| 1. 마지막 호송 (대사관 철수) | 험비·장갑차를 대사관 앞 승차 지점에 세워 피란민 20명을 태우고 서쪽 집결지로 데려오기 |
| 2. 강을 건너라 (다리 확보) | 5분 안에 서강교 폭약 해체, 동단 교두보 점령, 반격 2분 버티기 |
| 3. 목소리를 되찾다 (거점 탈환) | 요새가 된 중앙 방송국을 점령해 60초 지키기. 송신 중계소를 먼저 빼앗으면 적 화력 지원이 끊김 |


**AI 관전**: 새 게임 화면에서 세력 수(2~4)와 도시 크기를 고르면 모든 세력을 AI가 지휘하고 지켜보기만 합니다(자유 전투에서 모든 세력을 AI로 둬도 같음). 일시정지·1×·2×·4×·8× 배속(키보드 Space, 1~4), 전 세력 시야와 세력별 시야 전환, 부대를 탭해 따라가기, 교전이 뜨거운 곳을 알아서 따라가는 자동 연출을 쓸 수 있습니다. 전장은 자유 전투(지도 번호를 넣으면 같은 도시를 다시 볼 수 있음), 시나리오(도심 돌파·최후 방어), 캠페인 임무 중에서 고르고, 사람 자리는 AI가 맡습니다. 하단 바의 "기자 카메라"로 종군기자 시점을 켤 수 있고, 자동 연출 중이면 기자가 뜨거운 교전으로 옮겨 다닙니다. 관전 판은 저장하지 않고, 관전한 캠페인 판은 별을 기록하지 않습니다.

## 규칙 요약

- **승리:** 30초마다 거점 하나당 승점 +1. 승점 목표(거점 수×6+12)를 먼저 채우거나, 12분이 지났을 때 승점이 많으면 승리. 적 전멸도 승리
- **지휘점수:** 30초마다 3 + 거점당 2. 증원(집결지나 우리 거점 옆)과 화력 지원에 씁니다
- **엄폐:** 건물 40%, 잔해 25%, 공원 15% 피해 감소. 폭발물은 건물 엄폐를 절반만 받음
- **시야:** 건물이 시야를 막고, 높은 건물 안에서는 더 멀리·낮은 건물 너머까지 봄. 비 −1, 안개·폭우 −2
- **밤:** 시작 시각(아침·해질녘·한밤·새벽)을 고를 수 있고, 시간 흐름 모드(고정·실시간·느리게 3시간·보통 6시간·빠르게 하루, 한 판 12분 기준)도 고름. 밤에는 정규군 보병이 야간투시경(시야 −1), 민병대는 맨눈(−2), 차량·저격수·드론은 열상 장비로 덜 깎이고, 비추지 않은 적은 덜 맞음. 조명탄(지휘 1)은 40초 동안 둘레 4칸을 낮처럼 밝히고(양쪽 모두 보임), 불타는 건물도 주변을 비추며, 밤에 쏘면 총구 불꽃으로 드러남. N 키나 위의 버튼으로 야간투시경 화면
- **날씨:** 맑음·비·짙은 안개·폭우가 몇 라운드씩 이어지며 바뀜(고정도 가능). 비엔 드론이 느려지고 카메라가 흐려지며, 안개엔 드론이 땅을 거의 못 보고, 폭우엔 드론·헬기를 띄울 수 없고 떠 있던 드론이 떨어짐
- **건물 파괴:** 폭발물은 건물을 직접 쏠 수 있고, 내구가 0이 되면 무너져 잔해가 되며 안의 부대가 큰 피해
- **제압:** 기관총·폭발물에 맞으면 잠시 느려지고 공격 −30%
- **지휘:** 아군을 탭해 고르고 땅을 탭하면 이동, 적을 탭하면 쫓아가 공격. 사거리 안의 보이는 적은 자동으로 사격. Space로 일시정지, 0.5×·1×·2× 배속
- **무전:** 명령은 무전으로 1~3초 늦게 닿음(지휘소에서 멀수록, 명령을 몰아 내리면 차례를 기다림). 노란 점선이 아직 닿지 않은 명령. 적 전자전팀 재밍 반경 안에서는 무전이 끊겨 재송신하다 결국 전령이 전함(주황 점선). AI 명령도 같은 무전을 탐(한 번 생각할 때 내린 명령은 교신 한 번으로 묶음). 새 게임 설정에서 끌 수 있음
- **이동:** 칸에 묶이지 않고 찍은 지점으로 곧장 걸어감. 분대원은 흩어져 움직이고, 건물·잔해에서는 느려짐. 차량은 건물에 못 들어감. 아군을 두 번 탭하거나 "전체 선택"으로 여러 부대를 한 번에 지휘

## 경험치와 베테랑

- 분대는 싸우면서 경험을 쌓습니다: 적을 쓰러뜨리거나(전사·중상·경상), 차량·드론·분대를 끝내거나, 거점을 잡거나, 총알 속에서 버티거나, 전투 끝까지 살아남으면
- 계급: 신병 → 숙련(25) → 노련(65) → 정예(130). 계급마다 화력 +10%, 사격 간격 −5%, 제압이 빨리 풀리고 사기가 단단해짐. 이름표 옆 갈매기 휘장으로 표시
- 적을 셋 이상 쓰러뜨린 병사는 이름이 붙은 베테랑이 됩니다(별 표시). 노련 분대의 분대장도 이름을 얻습니다. 베테랑이 버티는 분대는 사상자가 나도 덜 흔들리고, 베테랑이 전사하면 사기가 크게 떨어집니다
- **고참 명부:** 자유 전투가 끝나면 살아남은 숙련 이상 분대가 명부에 오르고, 다음 작전에서 같은 병종 시작 부대로 돌아옵니다. 잃은 병사 자리는 신병이 채워 경험이 조금 묽어집니다. 전사한 베테랑은 시작 화면의 추모 명단에 남습니다

## 조작

| 하고 싶은 것 | 방법 |
| --- | --- |
| 부대 이동·사격 | 부대를 탭 → 파란 칸 이동, 빨간 칸 사격(한 번 더 탭하면 확정) |

## 개발

배포되는 `index.html`은 `src/`를 합쳐서 만든 단일 파일입니다. 직접 고치지 말고 `src/`를 고친 뒤 빌드하세요. 3D는 [three.js](https://threejs.org) 0.160(MIT)을 `vendor/`에 두고 처음 화면을 열 때 불러옵니다. 빌드에는 Node 18 이상만 있으면 됩니다.

```bash
npm run build      # src/ → index.html (+ dist/triad.html)
npm test           # 빌드 + 규칙 테스트 + AI 관전 게임
npm run balance -- 20 2   # AI 20판(2세력) 승률·병종별 격파 통계
```

| 경로 | 내용 |
| --- | --- |
| `src/head.html`, `src/style.css`, `src/body.html` | 페이지 머리, 스타일, 화면 뼈대 |
| `src/js/01-data.js` | 지형·병종·화력 지원 데이터 |
| `src/js/02-helpers.js`, `02b-audio.js` | 공용 함수, 효과음 |
| `src/js/03-mapgen.js` | 회전 대칭 도시 생성 |
| `src/js/04-rules.js` | 이동·시야선·전투·건물 파괴·증원·화력 지원 |
| `src/js/05-flow.js` | 새 게임·승패·저장 |
| `src/js/05b-realtime.js` | 실시간 진행: 칸에 묶이지 않는 자유 이동, 자동 사격, 30초 단위 수입 |
| `src/js/06-ai.js` | AI |
| `src/js/07-view3d.js` | 3D 전장(three.js): 도시·부대·연출·카메라 |
| `src/js/08-ui.js`, `09-input.js` | HUD·하단 바·메뉴, 입력 |
| `src/js/10-scenario.js` | 훈련·시나리오 |
| `src/js/10b-campaign.js` | 캠페인 임무: 지도 손질, 배치, 목표·승패, 별, 임무 선택·브리핑·결과 화면 |

| `test/` | node:test 테스트와 하네스 |
| `tools/balance.mjs` | 밸런스 측정 |

push하면 GitHub Actions가 테스트를 돌리고, `index.html`이 `src/`와 어긋나 있으면 실패합니다. 진행 상황은 브라우저에 자동 저장됩니다.
