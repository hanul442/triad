# TRIAD 전구사령부

육·해·공을 아우르는 턴제 전략 워게임입니다. 최대 6개 세력이 랜덤 생성된 전구에서 자원을 확보하고, 보급선을 유지하며, 참모부를 꾸려 싸웁니다. 각 세력은 사람이나 AI가 맡을 수 있고, 사람이 둘 이상이면 한 기기를 번갈아 씁니다.

**플레이:** https://hanul442.github.io/triad/

## 전체화면으로 하기

- **휴대폰:** 위 주소를 열고 브라우저 메뉴에서 "홈 화면에 추가"를 누르면 주소창 없이 전체화면 앱처럼 실행됩니다. 한 번 연 뒤에는 오프라인에서도 열립니다.
- **PC:** 지도 오른쪽의 전체화면 버튼을 누르거나 F11을 누르세요.

## 조작

| 하고 싶은 것 | 방법 |
| --- | --- |
| 부대 이동·공격 | 부대를 탭 → 파란 칸 이동, 빨간 칸 공격(한 번 더 탭하면 확정) |
| 상륙함 탑승 | 지상 부대를 고르면 근처 상륙함이 점선으로 표시, 탭하면 탑승 |
| 상륙 | 부대를 태운 상륙함을 고르면 내릴 해안이 초록으로 표시, 탭하면 상륙 |
| 점령 | 보병을 도시·자원지 위로 옮기거나 그 칸에 상륙하면 자동 점령 |
| 생산·건설·방어 시설 | 아군 도시나 영토 안 빈 땅을 탭 → 하단 바의 "생산·건설" |
| 참모부·연구·외교·교범 | 왼쪽 위 메뉴 버튼 |
| 다음 부대 / 턴 종료 | 아무것도 선택하지 않았을 때 하단 바 |

## 주요 시스템

- **자원:** 자금(도시), 철강(광산), 석유(유전·해상 유전)
- **보급선:** 수도·도시·보급창·보급트럭·항구·항공모함 반경 안에서만 연료·탄약 보급. 끊기면 전력 손실, 항공기는 추락
- **전선과 요새화:** 영토·전선 표시, 철책·벙커·지뢰지대, 참호
- **점령지 저항군**, 선두 세력을 견제하는 **AI 연합**
- **참모부**(G2·G3·G4·G7·G8·A3)와 매 턴 브리핑
- **연구** 10종, **외교**(불가침 조약·선전포고), **기상**과 **주야간**
- **미사일**(순항·탄도)과 요격, **해군**(함포사격·해상 봉쇄·항모)

## 파일

- `index.html` — 게임 전체 (단일 파일, 빌드 없음)
- `manifest.webmanifest`, `sw.js`, `icon*` — 홈 화면 설치와 오프라인 실행용

진행 상황은 브라우저에 자동 저장됩니다.
