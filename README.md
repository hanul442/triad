# TRIAD 전구사령부

육·해·공을 아우르는 턴제 전략 워게임입니다. 최대 6개 세력이 랜덤 생성된 전구에서 자원을 확보하고, 보급선을 유지하며, 참모부를 꾸려 싸웁니다. 각 세력은 사람이나 AI가 맡을 수 있고, 사람이 둘 이상이면 한 기기를 번갈아 씁니다.

**플레이:** https://hanul442.github.io/triad/

## 처음이라면

시작 화면의 **기초 훈련**부터 해보세요. 이동·점령·생산·공격·상륙·비행장 건설을 8단계로 안내합니다. 이어서 시나리오 3종이 있습니다.

| 시나리오 | 목표 |
| --- | --- |
| 섬 탈환 | 적이 점령한 중앙 섬 도시를 16라운드 안에 상륙으로 되찾기 |
| 방공망 돌파 | 적 수도를 지키는 SAM·대공포를 14라운드 안에 항공·미사일로 제거 |
| 해상 봉쇄 | 적 항구 도시를 함대로 둘러싸 3라운드 동안 봉쇄 |

모든 세력을 AI로 두면 **관전 모드**로 AI끼리의 전쟁을 지켜볼 수 있습니다.

## 전체화면으로 하기

- **휴대폰:** 위 주소를 열고 브라우저 메뉴에서 "홈 화면에 추가"를 누르면 주소창 없이 전체화면 앱처럼 실행됩니다. 한 번 연 뒤에는 오프라인에서도 열립니다.
- **PC:** 지도 오른쪽의 전체화면 버튼을 누르거나 F11을 누르세요.

## 조작

| 하고 싶은 것 | 방법 |
| --- | --- |
| 부대 이동·공격 | 부대를 탭 → 파란 칸 이동, 빨간 칸 공격(한 번 더 탭하면 확정) |
| 상륙함 탑승 | 지상 부대를 고르면 근처 상륙함이 점선으로 표시, 탭하면 탑승 |
| 상륙 | 부대를 태운 상륙함을 고르면 내릴 해안이 초록으로 표시, 탭하면 상륙 |
| 점령 | 보병을 도시·자원지 위로 옮기거나 그 칸에 상륙하면 자동 점령 |
| 생산·건설·방어 시설 | 아군 도시나 영토 안 빈 땅을 탭 → 하단 바의 "생산·건설" |
| 참모부·연구·외교·교범 | 왼쪽 위 메뉴 버튼 |
| 다음 부대 / 턴 종료 | 아무것도 선택하지 않았을 때 하단 바 |
| 장거리 이동 예약 | 부대 선택 → "목표 이동" → 먼 지점 탭. 매 턴 자동 이동, 적을 만나면 해제 |
| 경계 | 부대 선택 → "경계". 적이 3칸 안에 올 때까지 대기 목록에서 빠짐 |
| 도시 개발 | 아군 도시·수도 탭 → 생산·건설 → 도시 개발(최대 3단계) |
| 이동 경로 보기 | (PC) 부대를 고른 뒤 파란 칸에 마우스를 올리면 경로와 연료 소모 표시 |
| 효과음 끄기 | 지도 오른쪽 스피커 버튼 |

## 병종 (30종)

| 영역 | 병종 |
| --- | --- |
| 지상 | 보병, 대전차팀, 공병, 특수부대, 보급트럭, 정찰차, 장갑차, 전차, 자주포, 다연장로켓 |
| 방공·미사일 | 대공포, 단거리 SAM, 장거리 SAM(미사일 방어망 연구), 이동식 발사대(로켓 공학 연구) |
| 해상 | 상륙함, 고속정, 호위함(대잠), 구축함, 이지스 순양함(이지스 체계 연구), 잠수함, 전함, 항공모함, 보급함 |
| 공중 | 공격헬기, 수송헬기(공중강습), 무인기, 전투기, 스텔스기(스텔스 기술 연구), 폭격기, 조기경보기, 공중급유기 |

- **방공 반응 사격:** 적 항공기가 대공포·SAM·방공 함정의 사거리에 들어오면 즉시 자동 사격 (턴당 1회)
- **탄도탄 요격:** 장거리 SAM·이지스 순양함이 주변 4칸 탄도미사일을 요격
- **다연장로켓**은 목표 주변까지 피해, **특수부대·공병**은 철책·지뢰를 통과

## 게임 설정

- **승리 조건:** 정복(마지막 남은 세력) 또는 점수전(25·40라운드). 점수 = 도시·수도·자원지·개발 단계·격파·병력
- **지형:** 육지 크기(좁게·보통·넓게)와 지형 기복(완만·보통·험준)
- **AI 난이도:** 쉬움(수입 ×0.75) / 보통 / 어려움(수입 ×1.3, 약한 이웃 집중 공략)
- 게임이 끝나면 세력별 점수 추이 그래프와 전쟁 보고서가 나옵니다.

## 전투 규칙 추가

- **협공:** 적에게 붙은 아군 1기당 근접 공격 피해 +10% (최대 +30%)
- **제압:** 포병·다연장·폭격기·전함에 맞고 살아남으면 다음 턴 이동 −1, 공격 −30%
- **정찰위성**(연구): 4라운드마다 전 지도 정찰
- **시가전:** 도시·수도의 보병 계열은 받는 피해 −20%, 기갑이 도시를 근접 공격하면 −15%. 포격·폭격·미사일은 시가지를 최대 3단계까지 부수고(단계마다 그 도시 자금 −1, 연기와 잔해 표시), 3턴마다 1단계씩 복구
- **탄도미사일 타격 범위:** 목표를 탭한 뒤 집중(1칸 8) · 표준(중심 5, 주변 3) · 광역(반경 2칸, 4·3·2) 중 골라 발사

## 교역로와 도시 성장

- 도시·수도·자원지 사이에 도로가 깔려 있습니다. 양 끝을 같은 세력이 가지면 **교역로**가 열려 턴마다 자금 +2 (지도에 아군 색 점선이 흐름)
- 적 부대가 도로 위에 서면 차단됩니다(붉은 점선과 X). 정찰차·특수부대·헬기는 AI도 교역로 습격에 씁니다
- 수도와 교역로로 이어진 도시는 8턴마다 개발 단계가 저절로 1 오릅니다(최대 3)
- 지상 부대는 도로 칸을 이동 비용 1로 지나갑니다

## 기반시설

| 영역 | 시설 | 역할 |
| --- | --- | --- |
| 공군 | 비행장 | 활주로 2칸, 항공기 2대 격납, 항공기 생산 |
| 공군 | 격납고 | 비행장 옆, 1동마다 항공기 4대 추가 격납 |
| 해군 | 항구 | 함정 생산·보급 |
| 해군 | 조선소 | 항구 옆, 전함·항공모함·이지스 순양함 건조, 함정 수리 강화 |
| 육군 | 공장 | 차량 생산 |
| 육군 | 병기창 | 공장 옆, 전차·다연장로켓·장거리 SAM·이동식 발사대 생산 |

- 격납된 항공기는 매 턴 급유·재무장·수리되고 공격받지 않음. 비행장 칸을 눌러 출격, 활주로에 세운 항공기는 하단 바의 격납으로 보관
- 탄도미사일이 활주로에 떨어지면 2턴 복구, 비행장을 점령하면 격납 항공기 전부 파괴
- **공중급유기**·**보급함** 반경 2칸 안 아군은 기지 밖에서도 보급

## 주요 시스템

- **자원:** 자금(도시), 철강(광산), 석유(유전·해상 유전)
- **보급선:** 수도·도시·보급창·보급트럭·항구·항공모함 반경 안에서만 연료·탄약 보급. 끊기면 전력 손실, 항공기는 추락
- **전선과 요새화:** 영토·전선 표시, 철책·벙커·지뢰지대, 참호
- **점령지 저항군**, 선두 세력을 견제하는 **AI 연합**
- **참모부**(G2·G3·G4·G7·G8·A3)와 매 턴 브리핑
- **연구** 13종, **외교**(불가침 조약·선전포고), **기상**과 **주야간**
- **미사일**(순항·탄도)과 요격, **해군**(함포사격·해상 봉쇄·항모)

밸런스 측정 결과와 조정 내역은 [docs/balance.md](docs/balance.md)에 있습니다.

## 개발

배포되는 `index.html`은 `src/`를 합쳐서 만든 단일 파일입니다. 직접 고치지 말고 `src/`를 고친 뒤 빌드하세요. 외부 패키지는 필요 없고 Node 18 이상만 있으면 됩니다.

```bash
npm run build      # src/ → index.html (+ dist/triad.html)
npm test           # 빌드 + AI 관전 게임·시나리오·규칙 테스트
npm run balance -- 20 30   # AI 20판×30라운드 밸런스 측정 → docs/balance.md 참고용 수치
```
