# TRIAD 시가전

도시 한복판의 거점을 두고 분대 단위로 싸우는 3D 실시간 전술 게임입니다. 건물에 들어가 엄폐하고, 시야를 가리는 빌딩을 이용하고, 필요하면 건물째 무너뜨리세요. 2~4개 세력 중 하나를 사람이 지휘하고 나머지는 AI가 맡습니다.

**플레이:** https://hanul442.github.io/triad/ (main 브랜치 배포본)

**3D 시가전 개발 미리보기:** https://claude.ai/artifact/7zEiSXZZEW8Gu3uEPEhPPZ (feat/3d-urban 최신 빌드)

## 처음이라면

시작 화면의 **기초 훈련**부터 해보세요. 이동·엄폐·시야·사격·점령·증원을 6단계로 안내합니다.

| 시나리오 | 목표 |
| --- | --- |
| 기초 훈련 | 소형 도시에서 기본 조작 익히기 |
| 도심 돌파 | 적이 모든 거점을 쥔 도시에서 8분 안에 거점 5곳을 동시에 확보 |
| 최후 방어 | 도심 거점을 지키며 7분을 버티고 거점 3곳 이상 유지 |

## 캠페인: 하령 작전

가상의 내전 속 하령시에서 연방군을 지휘하는 임무 세 개입니다. 앞 임무를 마쳐야 다음 임무가 열리고, 임무마다 별을 세 개까지 받습니다(기록은 이 기기에 저장).

| 임무 | 목표 |
| --- | --- |
| 1. 마지막 호송 (대사관 철수) | 험비·장갑차를 대사관 앞 승차 지점에 세워 피란민 20명을 태우고 서쪽 집결지로 데려오기 |
| 2. 강을 건너라 (다리 확보) | 5분 안에 서강교 폭약 해체, 동단 교두보 점령, 반격 2분 버티기 |
| 3. 목소리를 되찾다 (거점 탈환) | 요새가 된 중앙 방송국을 점령해 60초 지키기. 송신 중계소를 먼저 빼앗으면 적 화력 지원이 끊김 |


**AI 관전**: 새 게임 화면에서 세력 수(2~4)와 도시 크기를 고르면 모든 세력을 AI가 지휘하고 지켜보기만 합니다(자유 전투에서 모든 세력을 AI로 둬도 같음). 일시정지·1×·2×·4×·8× 배속(키보드 Space, 1~4), 전 세력 시야와 세력별 시야 전환, 부대를 탭해 따라가기, 교전이 뜨거운 곳을 알아서 따라가는 자동 연출을 쓸 수 있습니다. 전장은 자유 전투(지도 번호를 넣으면 같은 도시를 다시 볼 수 있음), 시나리오(도심 돌파·최후 방어), 캠페인 임무 중에서 고르고, 사람 자리는 AI가 맡습니다. 하단 바의 "기자 카메라"로 종군기자 시점을 켤 수 있고, 자동 연출 중이면 기자가 뜨거운 교전으로 옮겨 다닙니다. 관전 판은 저장하지 않고, 관전한 캠페인 판은 별을 기록하지 않습니다.

## 규칙 요약

- **승리:** 30초마다 거점 하나당 승점 +1. 승점 목표(거점 수×6+12)를 먼저 채우고 2위보다 거점 수만큼(최소 8) 앞서거나, 16분이 지났을 때 승점이 많으면 승리. 적 전멸도 승리
- **최후 생존(승리 방식):** 새 게임·관전 설정에서 '최후 생존'을 고르면 승점으로 끝나지 않고 마지막까지 싸울 부대가 남은 세력이 이김. 8분에 증원·화력 지원이 끊기고 서로의 위치가 감청으로 드러나 AI가 남은 적을 찾아 나섬. 그 뒤 가장 센 세력의 15%도 안 되는 전력으로 45초를 버틴 세력은 항복. 15분이 되면 남은 전력이 큰 세력이 이김. 탈락하면 관전 카메라가 그 세력의 마지막 자리를 비춤(자유 전투만)
- **지휘점수:** 30초마다 3 + 거점당 2. 증원(집결지나 우리 거점 옆)과 화력 지원에 씁니다
- **엄폐:** 건물 40%, 잔해 25%, 공원 15% 피해 감소. 폭발물은 건물 엄폐를 절반만 받음
- **시야:** 건물이 시야를 막고, 높은 건물 안에서는 더 멀리·낮은 건물 너머까지 봄. 비 −1, 안개·폭우 −2
- **밤:** 시작 시각(아침·해질녘·한밤·새벽)을 고를 수 있고, 시간 흐름 모드(고정·실시간·느리게 3시간·보통 6시간·빠르게 하루, 한 판 12분 기준)도 고름. 밤에는 정규군 보병이 야간투시경(시야 −1), 민병대는 맨눈(−2), 차량·저격수·드론은 열상 장비로 덜 깎이고, 비추지 않은 적은 덜 맞음. 조명탄(지휘 1)은 40초 동안 둘레 4칸을 낮처럼 밝히고(양쪽 모두 보임), 불타는 건물도 주변을 비추며, 밤에 쏘면 총구 불꽃으로 드러남. N 키나 위의 버튼으로 야간투시경 화면
- **날씨:** 맑음·비·짙은 안개·폭우가 몇 라운드씩 이어지며 바뀜(고정도 가능). 비엔 드론이 느려지고 카메라가 흐려지며, 안개엔 드론이 땅을 거의 못 보고, 폭우엔 드론·헬기를 띄울 수 없고 떠 있던 드론이 떨어짐
- **건물 파괴:** 폭발물은 건물을 직접 쏠 수 있고, 내구가 0이 되면 무너져 잔해가 되며 안의 부대가 큰 피해
- **제압:** 기관총·폭발물에 맞으면 잠시 느려지고 공격 −30%
- **지휘:** 아군을 탭해 고르고 땅을 탭하면 이동, 적을 탭하면 쫓아가 공격. 사거리 안의 보이는 적은 자동으로 사격. Space로 일시정지, 0.5×·1×·2× 배속
- **무전:** 명령은 내리는 즉시 부대에 닿음(무전 지연 없음, 적 재밍도 명령을 늦추지 않음). 명령마다 무전기 "치익"과 함께 본부 호출·부대 수신 교신이 들림
- **무전 음성:** 부대들이 영어 군 무전 말투로 주고받음(기기의 영어 남자 목소리, 세력마다 다른 목소리·높이, 무전기 잡음). 본부 명령과 수신 응답, 위치 도착, 적 발견(방향·거리), 적 차량·항공 발견, 제압당함, 후퇴·재집결, 돌입·건물 소탕, 탄약 부족, 포격 요청과 탄착, 항공 지원 접근, 격파, 거점 확보·상실, 재밍 두절·전령, 사상자(몇 초씩 묶어 한 번에). 내 편만 들리고, 관전 중 전 세력 시야면 모든 세력. 소리 창의 '무전 말'(목소리·잡음·끔)과 '무전 자막'(영어·한국어 번역·끔). 영어 음성이 없는 기기는 무전 소리 + 자막
- **이동:** 칸에 묶이지 않고 찍은 지점으로 곧장 걸어감. 분대원은 흩어져 움직이고, 건물·잔해에서는 느려짐. 차량은 건물에 못 들어감. 차량은 서서히 가속·감속하고, 전차·장갑차(궤도)는 제자리에서 천천히 돌지만 험비·트럭(바퀴)은 달리면서 꺾고 좁은 곳에선 후진하며 방향을 바꿈. 가까운 뒤쪽은 돌아서지 않고 후진. 차체(사각형)는 벽·주차 차량을 파고들지 않음. 포탑은 차체와 따로 돌고, 표적 쪽으로 다 돌아가야 쏨(전차 40°/초, 장갑차 55°/초, 자주포 20°/초). 공격헬기는 목표에서 약 3.6칸 떨어져 제자리 비행으로 사격하다가 몇 초마다 목표를 비스듬히 스쳐 지나가는 사격 비행을 하고 옆으로 빠짐(기수 앞 40° 안만 쏨). 아군을 두 번 탭하거나 "전체 선택"으로 여러 부대를 한 번에 지휘

## 시가전 요소: 쥐구멍·지하·저격·폭파

- **쥐구멍:** 소총분대·공병의 "벽 뚫기"로 붙어 있는 건물 벽에 구멍을 냅니다(공병 3.5초, 소총 6초). 구멍은 문처럼 드나들 수 있고, 터질 때 벽 너머 적이 제압됩니다
- **지하실:** 일부 건물에 있습니다(칸 정보에 "지하실 있음"). 내려가면 포격·폭격·붕괴에 거의 안 다치고 적·드론에게 안 보이지만, 같은 칸에 들어온 적하고만 싸웁니다. 건물이 무너지면 잠시 갇힙니다
- **땅굴:** 공병이 건물·잔해 안에서 7칸까지 팝니다(지휘 2). 다 파면 아군 보병이 길찾기에서 알아서 쓰고, 안에 있는 동안은 보이지도 맞지도 않습니다. 적이 입구 가까이 오면 드러나고, 적 공병이 붙거나 큰 폭발이 나면 무너집니다
- **저격수:** 한 발에 한 사람(분대장을 먼저)을 노리고 치명상이 많으며, 맞은 분대는 크게 제압되고 흔들립니다. 쏘면 잠깐 위치가 드러나고 맞은 쪽 지도에 "저격 추정" 표시가 뜹니다
- **폭약:** 공병·소총분대가 건물에 폭약을 숨겨 둡니다(지휘 1). 적 보병이 들어오고 아군이 그 적을 보고 있으면 터져 건물이 무너집니다. 칸 정보에서 직접 터뜨릴 수도 있고, 아무도 안 볼 때 적 공병이 해체할 수 있습니다
- **자폭 차량(민병대 전용):** 적에게 몰고 가면 0.6칸 안에서 터집니다(반경 1.7칸). "지금 폭파"로 바로 터뜨릴 수 있고, 맞아 부서지면 그 자리에서 터지기도 합니다. 방벽·구덩이에 막힙니다

## 경험치와 베테랑

- 분대는 싸우면서 경험을 쌓습니다: 적을 쓰러뜨리거나(전사·중상·경상), 차량·드론·분대를 끝내거나, 거점을 잡거나, 총알 속에서 버티거나, 전투 끝까지 살아남으면
- 계급: 신병 → 숙련(25) → 노련(65) → 정예(130). 계급마다 화력 +10%, 사격 간격 −5%, 제압이 빨리 풀리고 사기가 단단해짐. 이름표 옆 갈매기 휘장으로 표시
- 적을 셋 이상 쓰러뜨린 병사는 이름이 붙은 베테랑이 됩니다(별 표시). 노련 분대의 분대장도 이름을 얻습니다. 베테랑이 버티는 분대는 사상자가 나도 덜 흔들리고, 베테랑이 전사하면 사기가 크게 떨어집니다
- **고참 명부:** 자유 전투가 끝나면 살아남은 숙련 이상 분대가 명부에 오르고, 다음 작전에서 같은 병종 시작 부대로 돌아옵니다. 잃은 병사 자리는 신병이 채워 경험이 조금 묽어집니다. 전사한 베테랑은 시작 화면의 추모 명단에 남습니다

## 특별 거점

거점마다 생김새와 쓰임이 다릅니다. 차지한 세력만 그 효과를 받습니다(캠페인에서는 모습만 바뀜). 탭하면 거점 설명에 효과가 나옵니다.

**점령:** 주인 없는 거점은 밟으면 바로 확보합니다. 남의 거점은 보병이 거점 땅에 12초 버텨야 넘어오고, 주인 쪽 병력이 둘레 1칸 안에 있으면 '다툼'으로 멈춥니다. 요새화한 건물은 1.6배, 곁에 벙커가 있으면 1.3배 더 걸립니다. 진행은 거점 이름 옆에 %로 나옵니다.

| 거점 | 모습 | 차지하면 |
| --- | --- | --- |
| 종합병원 | 옥상 헬기장, 붉은 십자 | 후송된 중상자를 받아 60%를 분대로 돌려보냄, 둘레 2칸 경상자 치료. 빼앗기면 누워 있던 환자는 포로 |
| 방송국 | 붉은·흰 송신 철탑 | 우리 보병 사기 회복 1.5배, 차지하는 순간 다른 세력 보병 사기 −10 |
| 통신탑 | 높은 격자 철탑, 깜박이는 등 | 둘레 4칸 우리 드론은 재밍에 안 끊김, 둘레 5칸 감시 |
| 발전소 | 줄무늬 굴뚝, 변압기 | 지휘점수 +2 /30초 |
| 중앙역 | 둥근 지붕, 시계탑 | 둘레 2칸에서 증원, 증원 비용 1 환급 |
| 중앙시장·항만청 | 차양 노점 / 컨테이너와 기중기 | 둘레 2칸 탄약 보충·차량 정비·보급 트럭 재적재 |
| 대성당 | 뾰족 첨탑 | 아군이 곁에 있으면 둘레 7칸 감시 |

| 증권거래소 | 금빛 박공 | 지휘점수 +1 /30초, 차지할 때마다 +4 |
| 국립도서관 | 넓은 계단, 청동 지붕 | 둘레 4칸 건물 속 적이 보임(설계도) |
| 경찰청 | 경광등, 바리케이드 | 둘레 2칸 보병 탄약 보충, 둘레 2칸에서 증원한 보병은 숙련으로 시작 |
| 공항 터미널·스타디움 | 관제탑 / 둥근 관중석 | 둘레 2칸에서 드론·항공 증원, 항공 증원 비용 1 환급 |

감시는 높은 곳에서 내려다보는 것이라 그 안의 적은 우리 모든 부대에게 보이고 쏠 수 있습니다.

## 진지 구축과 의료

보병을 고르고 **축성**을 누르면 방어물을 짓습니다(지휘점수 소모, 공병은 1.8배 빠름).

| 방어물 | 누가 | 효과 |
| --- | --- | --- |
| 모래주머니·철조망·참호·기관총 진지·콘크리트 방벽·대전차 장애물 | 보병(종류는 병종마다) | 엄폐와 길 막기 |
| 대전차 지뢰 | 공병 | 적에게 안 보임. 적 차량이 밟으면 궤도가 끊기고 크게 다침. 보병은 안 터짐. 적 공병이 가까이 오면 찾아 걷어 냄 |
| 벙커 | 공병 | 지붕 덮인 토치카. 안의 보병 사방 엄폐 60%(포격에도), 차량 차단 |
| 건물 요새화 | 보병 | 지금 있는 건물 칸 창을 모래주머니로 막음. 엄폐 40% → 55%(옥상 25% → 45%), 건물 피해 −30% |
| 구호소 | 보병 | 앞쪽 응급 천막. 부상자를 출발 지역까지 안 데려가고 여기로 후송, 둘레 경상자 치료 |
| 개인호 | 보병 (저절로) | 맨땅에 6초 넘게 멈춘 보병이 명령 없이 판다. 안의 병사 사방 엄폐 50%(포격 파편도 막음). 지휘점수 없음 |
| 차량 진지 | 공병 | 차체 엄폐호. 안의 전차·장갑차는 포탑만 내놓아 직사 엄폐 40%, 포격 피해 −40% |
| 대전차호 | 공병 | 모든 차량을 막는 도랑. 보병은 건넘. 공병전차가 메우거나 공병이 폭파 |
| 관측소 | 보병 | 우리 보병이 곁에 있으면 둘레 4칸을 계속 지켜봄 |
| 탄약 집적소 | 소총·기관총·공병 | 둘레 부대가 트럭 없이 탄약을 채움(재고 60, 곁에 선 보급 트럭이 다시 채움). 맞으면 유폭 |
| 지휘소 | 소총·기관총·공병 | 둘레 2.5칸 아군 사기 회복 2배, 제압이 빨리 풀림 |
| 위장망 | 보병 | 그 아래 멈춘 부대(차량 포함)는 쏘지 않으면 적이 훨씬 가까이 와야 봄 |

**모두가 알아서 하는 일(공성전):** 맨땅에 멈춘 보병은 개인호를 파고, 쉬는 보병은 곁의 부서진 우리 방어물을 고칩니다. 공병은 바로 앞(1칸) 적 철조망·지뢰·장애물·대전차호를 걷어 내거나 폭파합니다. AI와 부관은 잡은 거점마다 위협 방향을 보고 진지를 넓혀 갑니다: 1선 참호·기관총 진지 → 뒤쪽 구호소·탄약 집적소 → 앞쪽 철조망 지대 → 관측소 → 지휘소 → (공병) 벙커·차량 진지·대전차호 → 위장망. 위협받는 거점부터 짓고, 지휘점수 일부(위협 시 6, 평소 3)를 증원보다 먼저 떼어 둡니다. 공격할 때는 주공 집결지에 구호소·탄약 집적소를 세우고(전진 지원 거점), 주공의 공병이 목표 둘레 적 벙커·기관총 진지·방벽·장애물을 연막을 치고 다가가 폭파하므로 공성이 길어져도 영원히 막히지는 않습니다.

**승리:** 승점 기준에 먼저 닿아도 2위보다 거점 수만큼(최소 8) 앞서야 이깁니다. 비등하면 시간 끝(기본 16분)까지 싸워 승점이 많은 쪽이 이깁니다.

**치료와 복귀:** 업혀 간 중상자는 가장 가까운 의료 시설(출발 지역 환자집결지·구호소·우리 종합병원·기다리는 구급차)에 넘겨지고, 치료가 끝나면 일부가 걸어서 원래 분대로 돌아옵니다(환자집결지 25%, 구호소 30%, 병원 60%). **구급차**(3)는 부상자가 생긴 분대 뒤 안전한 곳에 서서 후송조를 받고, 넷을 실으면 병원·구호소로 달려갑니다. 구급차가 부서지면 실린 환자도 죽습니다. 분대가 끝난 자리에 남겨진 부상자는 쉬는 구급차가 먼저 실어 가고, AI는 근처에서 쉬는 분대를 보냅니다. 아군이 없는 곳에서 적 보병이 지나가면 포로로 잡혀 갑니다.

**구급차 안전:** 구급차는 적이 3.2칸 안에 보이거나 맞으면 하던 일을 버리고 물러나고(실었으면 시설로), 그 분대에는 30초 동안 다시 가지 않습니다. 둘레에서 적이 방금 쏜 교전 현장에는 들어가지 않습니다. AI는 구급차를 잃으면 60초 동안 새로 사지 않습니다.

**제네바 협약:** 구급차·구호소·환자집결지는 보호 대상입니다. 협약을 지키는 세력의 부대는 이들을 스스로 겨누지 않고, AI는 그 둘레에 포격·폭격을 부르지 않습니다(다른 적을 치다 휘말리는 피해는 막지 않음). 일부러 쏘면(직접 공격 명령, 그 자리에 지원 사격) 위반이라 승점 −2, 쏜 세력 보병 사기 −4, 맞은 세력 사기 +3이고, 무전 기록과 관전 화면에 나옵니다. 구호소 곁에서 그 세력 부대가 사격하면 30초 동안 보호를 잃습니다. 새 게임 설정 **제네바 협약**: 민병대는 무시(기본, 앰버 민병대 AI는 보호 대상도 쏨) · 모두 지킴 · 끄기.

## 개발

배포되는 `index.html`은 `src/`를 합쳐서 만든 단일 파일입니다. 직접 고치지 말고 `src/`를 고친 뒤 빌드하세요. 3D는 [three.js](https://threejs.org) 0.160(MIT)을 `vendor/`에 두고 처음 화면을 열 때 불러옵니다. 빌드에는 Node 18 이상만 있으면 됩니다.

```bash
npm run build      # src/ → index.html (+ dist/triad.html)
npm test           # 빌드 + 규칙 테스트 + AI 관전 게임
npm run balance -- 20 2   # AI 20판(2세력) 승률·병종별 격파 통계
```

| 경로 | 내용 |
| --- | --- |
