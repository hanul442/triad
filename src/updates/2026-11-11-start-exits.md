# 시작하자마자 부대가 갇혀 못 나오던 문제 수정 (#PR)
- 출발 지점 둘레의 주차된 차·바리케이드·울타리가 큰길로 나가는 길을 모두 막아, 장갑차나 일부 보병이 처음부터 못 나오던 일이 있었어요.
- 이제 판이 시작될 때 출발 지점에서 시가지로 나가는 길을 확인하고, 막혀 있으면 길을 막은 차와 장애물만 치워 둬요. 건물·강·성벽은 그대로예요.
- 모든 지도 종류와 크기, 네 세력 출발 지점, 캠페인·역사 전투 임무를 자동으로 검사해요.
- 장갑차를 따라가던 분대가 출발 자리 근처에서 앞뒤로 맴돌며 못 떠나던 일도 고쳤어요.
