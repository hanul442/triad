# 3D 시가전 게임으로 새로 태어남 (#1)
- 판 위의 말 대신 입체 도시에서 분대·전차·헬기가 실시간으로 싸웁니다.
- 건물 안 엄폐, 빌딩에 가린 시야, 건물째 무너뜨리기가 들어왔어요.

# 전장의 안개와 방향 엄폐 (#2)
- 칸이 아니라 실제 거리와 각도로 보이고 가려집니다. 적이 보이는 쪽에서만 엄폐가 통해요.

# 현대 부대와 도시 소품 (#3)
- 험비·자주포, 방탄복 차림 보병이 생겼고 도시에 주차된 차·신호등·상가·공원·연못이 놓였어요.

# 병사 차림과 장비가 다양해짐 (#4)
- 정규군과 민병대 차림이 달라지고, 분대 인원이 늘고, 기관총을 단 픽업트럭(테크니컬)이 나와요.

# 미국식 대도시 지도 (#5, #9)
- 대로·골목·주차장·구역이 있는 큰 도시. 대각선 대로·순환로·원형 광장으로 바둑판 느낌을 깼어요.

# 문으로 드나들고 계단으로 오르기 (#6, #8, #15)
- 보병은 문으로 건물에 들어가 계단으로 옥상까지 오릅니다. 벽을 뚫고 지나가던 문제도 고쳤어요.

# 분대 병사가 한 명씩 움직임 (#7)
- 분대가 한 덩어리로 미끄러지지 않고, 병사들이 각자 걸어 자리를 잡아요.

# 바리케이드 쌓기 (#10)
- 길을 막는 바리케이드를 세울 수 있고, 차량은 장애물을 넘지 못하고 돌아갑니다.

# 공중 지원과 드론전 (#12, #13, #16)
- 공격헬기·전투기·FPV 드론과 대공 무기, 격추가 생겼어요. 드론팀은 차에서 내려 드론을 띄워요.

# 부상자 수습 고침 (#14)
- 출혈·수습이 멈추거나 부상자 수가 음수가 되던 문제를 고쳤어요.

# 새 기능 한꺼번에 (#17–#30)
- 분대 경험치와 이름 붙은 베테랑, 대전차 미사일·다연장 로켓·탄도미사일이 생겼어요.
- 전투가 끝나면 폐허 지도·리플레이·항공 사진·통계를 볼 수 있어요.
- 거리와 메아리가 실린 총소리, 폭발, 헬기·드론 소리가 들려요.
- 탄약이 닳고 보급 트럭이 채워 주며, 구난차가 부서진 차를 끌고 가 고쳐요.
- 밤 전투(야간투시경·조명탄)와 비·안개·폭우 날씨가 생겼어요.
- 캠페인 '하령 작전', 종군기자 카메라, AI끼리 싸우는 관전 모드가 생겼어요.
- AI가 장갑차·자주포·공중 지원을 섞어 싸우고, 큰 지도가 2~3배 빨라졌어요.
