# 무전이 실제 군 무전처럼, 여러 말투로 (#PR)
- 호출부호가 실제 부대처럼 소대-분대 번호가 됐어요(Rifle One-One, Sabre Two-One, 지휘관은 Eagle Six).
- 같은 일에도 말투가 여러 가지라 같은 말이 연달아 나오지 않아요. Over·Out·Roger·Wilco, "여기는 ○○, 이상", "알았음, 끝" 같은 절차어를 제대로 써요.
- 적 차량·헬기를 보면 SPOT 보고(몇 대, 어디로 가는지, 좌표, 시각)를 올려요.
- 중상자가 나오면 9-line 환자 후송 요청이 오고, 본부가 구급차를 보내거나 환자 집결점으로 옮기라고 답해요.
- 포격은 사격 요청 → 포대 복창 → 발사 → 탄착 → 사격 종료 순서로 오가요. 아군 가까이 떨어지면 "근접 위험"을 붙여요.
- 가끔 본부가 상황 보고(SITREP)를 부르면 한 부대가 위치·전투력·탄약·접적 여부를 보고해요.
- 소리 창에 '무전 언어'가 생겼어요. 한국어로 고르면 한국어 목소리로, 숫자는 군대식("하나 다시 하나")으로 읽어요.
