# 업데이트 로그 쓰는 법

게임 시작 화면의 [업데이트 로그] 창에 나오는 글입니다. `npm run build`가 이 폴더의 `.md` 파일을 모두 읽어 게임에 넣습니다.

- PR 하나에 파일 하나: `YYYY-MM-DD-짧은이름.md` (예: `2026-11-11-update-log.md`). 날짜는 머지하는 날(UTC)입니다.
  파일을 따로 두니 여러 PR이 같이 올라와도 서로 충돌하지 않습니다.
- `# 제목 (#PR번호)` 한 줄이 업데이트 하나입니다. 제목은 플레이어가 알아듣는 쉬운 말로 씁니다.
- 그 아래 `- `로 시작하는 줄이 설명입니다. 무엇이 달라졌는지 한두 줄로, 코드 이름 없이 씁니다.
- 한 파일에 `#` 제목을 여러 개 써도 됩니다. 날짜가 최신인 것부터 보이고, 같은 날짜 안에서는 파일 이름 역순(이름이 뒤인 파일이 위), 파일 안에서는 쓴 순서대로 보입니다.
- 이 README.md는 게임에 들어가지 않습니다.

```
# 교범대로 싸우는 습관 9가지 (#126)
- 기관총이 짧게 끊어 쏘고, 오래 쏘면 총열을 갈아요.
- 분대장이 쓰러지면 다음 사람이 지휘를 이어받아요.
```
