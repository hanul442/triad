# 조작 쉽게: 목표 한 번, 증원 한 번 (#147)
- 하단 바에 노란 [목표] 버튼이 생겼어요. 누르고 지도를 탭하면 모든 부대가 그곳을 칩니다.
- 증원 메뉴 맨 위에 빠른 증원 묶음(부관 추천·보병 소대·대전차조·기계화 분대·전차)이 생겼어요. 한 번 탭하면 목표 가까운 집결지로 바로 들어와요.
- 지휘점수가 모자라면 예약돼서 모이는 대로 들어와요. 낱개 부대도 초록 칸을 고를 필요 없이 탭 한 번이면 돼요.
- 휴대폰에서는 증원 메뉴를 보는 동안 전투가 멈춰요(PC는 메뉴 안 [메뉴 볼 때 멈춤]으로 켜요). 메뉴만 보다 판이 끝나지 않아요.
- 처음 자유 전투를 열면 세 단계 안내가 떠요.
