# 국군 장비로 싸우기 (#PR)
- 자유 전투 시작 화면에서 세력마다 '기본 장비'와 '국군 장비'를 고를 수 있어요. 처음엔 블루 연방군이 국군 장비예요.
- 국군 세력은 K2 흑표 전차, K21 보병전투차, K808 백호 장갑차, KLTV 소형전술차량, K600 코뿔소, K9A1 자주포, K239 천무, K30 비호복합, K263A1 자주발칸으로 싸워요. 모형도 실제 생김새를 따랐어요.
- 병사는 디지털 위장복에 위장 덮개 방탄모, K2C1 소총·K15 기관총·현궁·신궁·판처파우스트3 이름을 써요.
- 헬기 투입은 수리온, 공격헬기는 AH-64E 아파치, 미사일은 현무-2·현무-3으로 나와요.
- 국군만 쓰는 천궁(KM-SAM)이 생겼어요. 지상은 못 쏘지만 지도 전체의 적 헬기·폭격기를 떨어뜨리고 순항·탄도미사일을 요격해요.
- 천무는 유도 로켓 6발을 표적 둘레에 모아 떨어뜨려요.
